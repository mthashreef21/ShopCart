# ShopCart 🛒

A modern e-commerce frontend built with React.js.

## Technologies Used

- React.js
- JavaScript
- Tailwind CSS
- Redux
- Vite

## Features

- Responsive navigation bar
- Hero banner
- Product categories
- Flash deals
- Product listings
- Shopping cart interface

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/mthashreef21/ShopCart.git '''


### 2. API Data

ShopCart uses the DummyJSON API to fetch product data.

**API Endpoint:** https://dummyjson.com/products?limit=0
